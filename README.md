# OpenRGB Deck 🎨

An unofficial [Elgato Stream Deck](https://www.elgato.com/stream-deck) plugin for controlling [OpenRGB](https://openrgb.org/) profiles — switch profiles from a key, see the active profile live, and push a fixed colour to your devices.

> **Work in progress.** Nothing works yet; the first release will be v0.1.0.
